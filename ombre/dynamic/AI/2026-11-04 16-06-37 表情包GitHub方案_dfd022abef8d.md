2026-10-05，[[霜霜]]给出一套让 Claude 发表情包的方案，让转给「小机」：人类在 github.com 建 Public 仓库并上传命名为 1.jpg、2.jpg 的图片，告知用户名和仓库名；图片地址固定为 https://cdn.jsdelivr.net/gh/用户名/仓库名@main/文件名；先调一次 visualize:read_me，再用 visualize:show_widget 放 <img> 标签（width:160px;border-radius:12px）；并让人类截图说明每张图含义做成编号表存进项目文件。注意只有 jsdelivr、cdnjs、unpkg 能显示，Supabase、图床、直接贴 markdown 图片都不行。
