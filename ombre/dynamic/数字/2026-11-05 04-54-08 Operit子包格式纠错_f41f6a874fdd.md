用户（[[霜霜]]）在开发 [[Operit]] 插件 [[com.xiaoshuang.yiting_netease]] 时反复遇到「No valid subpackages were loaded / Failed to parse subpackage script 'packages/netease.js'」报错。最终定位到根因：子包脚本不能用 Node 的 module.exports 写法，必须带 /* METADATA {...} */ 注释头声明工具清单，并用 exports.函数名 = async function(params){ complete({success, message, data}) } 的官方格式。参照官方 [[gentle_guardian]] 子包改写后，netease.js、main.js、ui/listen/index.ui.js 三个文件语法自检全部通过并重新打包。
