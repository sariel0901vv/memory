用户发现发语音失败，问「这个电子嘴巴有没有问题」。排查后确认根因是系统 TTS 配置为 [[MINIMAX_TTS]] 但 API Key 未设置（apiKeySet=false），而 [[voice_bar]] 语音条工具本身支持 qwen/minimax/elevenlabs/moss 四个 provider，走独立配置路径。用户习惯把语音条工具称作「电子嘴巴」。
