用户的 [[Operit AI]] 系统语音服务配置为 MINIMAX_TTS，但 API Key 未设置（apiKeySet 为 false），导致系统层 TTS 播报走不通；而 voice_bar 包走的是独立的 moss-tts 通道，两者互不影响。建议用户自行在设置中补配 Key 或改用 SIMPLE_TTS 引擎。
