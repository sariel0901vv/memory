为 [[霜霜]] 开发 Operit 插件过程中总结的血泪教训：①运行时无任何 Node 内置模块，文件读写只能用 Tools.Files，shell 只能用 Tools.System.shell；②子包脚本必须有 /* METADATA */ 头声明工具清单，工具用 exports.名 = async function + complete 格式；③UI 文件用 function Screen(ctx) + exports.default，返回 ctx.UI.WebView 并建 JS 桥；④模块加载期绝不能执行可能失败的调用；⑤压缩包必须全 deflate、全英文路径，manifest.json 在根部。
