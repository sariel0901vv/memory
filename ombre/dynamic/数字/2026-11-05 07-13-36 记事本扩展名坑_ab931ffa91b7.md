[[霜霜]]用 Windows 记事本创建 docker-compose.yml 时被自动加上 .txt 后缀，实际文件名变成 docker-compose.yml.txt，导致她怀疑扩展名不对；解决办法是开启文件资源管理器「显示文件扩展名」后重命名，或直接用 VS Code 新建文件。
